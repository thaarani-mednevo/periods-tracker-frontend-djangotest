# Onboarding assets

`period-tracker-girl.webp` is the approved Mednevo guide character: a transparent WebP (1024×1536) used unmodified on every onboarding step, the success screen and the dashboard.

It's referenced from `src/components/visuals/GuideGirl.tsx` (`GUIDE_GIRL_SRC`). To replace it, keep the same file name, or update that constant. Keep the transparent background and portrait framing: the layout expects her pointing hand at the upper right of the image.
